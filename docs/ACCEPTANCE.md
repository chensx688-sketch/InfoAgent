## 失败时怎么反馈

记录：机型 + 系统版本 + 操作序号 + 现象截图。优先排查：
1. 通知使用权是否被系统回收（消息页顶部横幅会提示）
2. 厂商省电策略是否冻结后台（设置 → 电池 → 允许后台/自启动）
3. API 是否可用（简报页错误文案会区分 401/429/5xx/断网）
